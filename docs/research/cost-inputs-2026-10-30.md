## Caveats

1. **The AWS RDS and S3 pricing pages load their prices client-side.** The fetched HTML had no rate tables. The RDS and S3 figures above come from AWS's official machine-readable Price List API (us-east-1 regional offer files), not from the marketing pages. SES prices were present in the page HTML.
2. **Razorpay's page gives two different figures.** The FAQ says "2% + GST" several times, and a separate line says "Platform fee 2.15% + GST". It is not stated which applies to which payment method. The page lists no separate rates for international cards, Amex, Diners, corporate cards, EMI, netbanking or wallets. The current 0%-for-90-days offer is promotional. GST, currently 18% in India, is added on top; the page does not state the rate.
3. **OpenAI has no model named "mini" in its current pricing table.** openai.com/api/pricing returned ChatGPT Business seat pricing ($20/$25 Standard, $100/$125 Premium per seat per month) and no API token prices. API prices came from developers.openai.com/api/docs/pricing. Its cheapest current text model is gpt-6-luna. gpt-5.4-mini still has a model page but does not appear in the main pricing table. The pricing page has a Short/Long context toggle whose tables could not be clearly told apart; the 272K long-context multipliers come from the gpt-6-luna model page.
4. **Gemini 3.8 Flash prices are time-limited.** The current rates are introductory and double on 2027-01-01. Use the 2027 rates in any forward-looking model.
5. **Claude Haiku 5.5 has a long-context surcharge.** It is the only current Claude model with one: prompts over 100K tokens pay 5x on input and output. Data-residency (US-only) inference costs 1.1x. Sonnet 5.5 is a flat rate across the 1M-token context.
6. **Twilio's total cost per segment is higher than the base rate.** The $0.0083 base plus a carrier fee comes to about $0.0118–$0.0133. 10DLC and toll-free registration fees were not captured.
7. **Some figures come from summaries, not raw HTML.** The Stripe, Razorpay, SES, Twilio, Gemini and OpenAI figures were read through a page-fetch tool that summarises and quotes page text. The Claude figures were also checked against the raw HTML. The AWS RDS and S3 figures were parsed directly from AWS price files. Spot-check the Stripe and Twilio figures in a browser before the model is used externally.
8. **These are list prices.** Negotiated, volume or committed-use discounts are not included.
